# 🌦️ Weather Impact Analysis Dashboard

An interactive Power BI dashboard created to explore weather trends, environmental conditions, and their impact through clear and engaging visualizations. This project focuses on transforming weather-related data into meaningful insights using interactive charts, filters, and analytical storytelling.


# **📌 About the Project**

I created this dashboard to improve my skills in Power BI, data visualization, and dashboard design. The goal of the project was to build a clean and interactive report that helps users explore weather patterns across different cities, months, and weeks.

The dashboard provides insights into temperature trends, weather distribution, environmental indicators, and weather impact analysis through dynamic and user-friendly visuals.


# **🛠️ Tools & Technologies Used**
- **Power BI Desktop** – Used for building the interactive dashboard  
- **Power Query** – Used for data cleaning and transformation  
- **DAX** – Used for calculated measures, KPIs, and dynamic analysis  
- **Data Visualization** – Interactive charts and graphical insights  
- **Dashboard Design** – Modern and user-friendly dashboard interface  

# **📂 Dataset Information**

The dataset contains weather-related information such as:

- City-wise weather details  
- Temperature trends  
- Weather conditions like Sunny, Rainy, Cloudy, Fog, and Storm  
- Monthly and weekly analysis  
- Environmental indicators  
- Sunrise and sunset timings  

The data was cleaned, transformed, and organized to create an interactive and easy-to-understand dashboard experience.


# **✨ Dashboard Highlights**

## **🔹 Interactive Filters**

Users can filter the dashboard using:

- City  
- Weather Type  
- Year  
- Month  
- Week  

These filters make it easier to explore specific trends and weather conditions.


## **🔹 KPI Cards**

The top section of the dashboard displays important environmental metrics such as:

- CO2 Levels  
- Temperature  
- Ice and Ice Sheet Values  
- Sea Levels  
- Warm Temperature Indicators  

These KPIs provide a quick summary of environmental insights.


## **🔹 Weather Impact on Sales**

A bar chart visualizes how different weather conditions impact sales-related trends.  
The analysis highlights that sunny weather shows the highest overall impact compared to other weather conditions.


## **🔹 Monthly Temperature Trends**

A line chart displays temperature changes across different months and helps identify seasonal patterns and variations.


## **🔹 Sunrise & Sunset Insights**

The dashboard includes sunrise and sunset timings based on selected locations and filters for better environmental analysis.


## **🔹 Weather Distribution Charts**

Donut and pie charts are used to represent:

- Weather frequency breakdown  
- Regional weather distribution  

These visuals make comparison and analysis easier.


## **🔹 Weekly Temperature Analysis**

This section tracks weekly temperature fluctuations and helps identify short-term weather patterns and changes.


# **📈 Key Insights**

- Sunny weather appears most frequently in the analysis  
- Temperature levels rise during the middle months of the year  
- Weather conditions vary across regions and time periods  
- Interactive filtering makes data exploration faster and more effective
